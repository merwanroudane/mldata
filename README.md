# تعلّم الآلة من الصفر — Machine Learning From Scratch

تطبيق **Streamlit** تفاعلي باللغة العربية (مع المصطلحات الإنجليزية) يشرح
أساسيات تعلّم الآلة للمبتدئين تماماً — بلا أي خلفية سابقة.

**إعداد: Dr Merwan Roudane**

---

## محتوى الدورة

الترتيب مقصود: **الجزء الأول بلا رياضيات تقريباً** (الفكرة العامة للتدريب
للمبتدئين من الصفر)، ثم ننزل إلى التفاصيل الرياضية، ثم إلى الممارسة.

## ملاحظات تصميمية

- **الشريط الجانبي على اليمين** واتجاه القراءة RTL — عبر طبقة CSS في
  `utils/style.py` (الكود والصيغ والرسوم تبقى LTR).
- **ألوان فاتحة فقط**: السمة معرّفة في `.streamlit/config.toml` ومقفلة على
  الوضع الفاتح (لا يوجد وضع داكن).
- **الحركة (Animation)**: طبقة `@keyframes` في `utils/style.py` للبطاقات
  والشرائط والمخطّطات، إضافة إلى إطارات Plotly (`frames`) مع أزرار تشغيل
  في المختبرات المتحرّكة.
- **المخطّطات**: Mermaid للمخطّطات المفاهيمية، و Plotly لكل ما هو تفاعلي
  أو متحرّك أو ثلاثي الأبعاد.

## بنية المشروع

```

.streamlit/config.toml    السمة الفاتحة والخطوط وألوان المخطّطات
app_pages/                الدروس الثلاثة عشر
utils/
    style.py              طبقة RTL + الحركة + بنّاؤو البطاقات
    viz.py                قالب Plotly الفاتح وأدوات الحركة
    data.py               مولّدات بيانات اصطناعية مُخزّنة مؤقتاً
```
